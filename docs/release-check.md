# Проверка перед публикацией

## Вердикт

Фронтенд — музыкальный плеер, темы и трёхмерный двор — прошёл локальную проверку и подготовлен к публикации. Исходные изменения из другого редактора сохранены, дизайн и фирменные тексты не заменялись.

**Полный публичный запуск с общим чатом и входом требует настройки инфраструктуры:** HTTPS reverse proxy, same-origin `/api`, постоянно работающий Python backend, постоянная SQLite-база и SMTP. Это не создаётся публикацией в Object Storage. Реальный сервер, доставку почты и CDN в этой проверке не настраивали и не проверяли. Требования: [release-deployment.md](release-deployment.md).

Ни публикации, ни коммита/пуша не выполнялось.

## Исправления и воспроизведение

| Область | Найденная проблема | Исправление / проверка |
|---|---|---|
| Адаптивный чат | На ширине 800–1024 px боковая панель закрывала плеер; Tab уходил под панель | До 1100 px ширины или 540 px высоты — отдельный экран чата, удержание фокуса, Escape/сворачивание; при переходе из широкого режима чат сворачивается |
| Ввод в чате | Нужно учитывать уменьшение видимой области клавиатурой | Размер и смещение панели связаны с VisualViewport; поле ввода и закрытие остаются внутри панели. Реальная экранная клавиатура iOS отдельно не тестировалась |
| История чата | Опрос заново строил DOM и сбрасывал чтение в конец | Неизменившиеся сообщения не перерисовываются; положение прокрутки сохраняется; анимация букв отключена в компактном режиме и ограничена на десктопе |
| Мобильная компоновка | Ссылка «на улицу» перекрывала треки, счётчик мешал ссылке; маленькая кнопка закрытия трека | Ссылка перенесена в верхнюю полосу, декоративный счётчик скрыт на компактных устройствах, область нажатия закрытия — 44×44 px |
| Плеер | Пустые поля `file` ошибочно совпадали и выбирали индекс первого трека | Сравниваются только заданные пути; тест выбора второго audio-only трека |
| Переход домой/во двор | Сохранённые 42 секунды превращались в 0 до загрузки метаданных; старое восстановление влияло на следующий трек | Сохранение заблокировано до восстановления, устаревшие обработчики отменяются/проверяются; поведенческие тесты |
| Двор на телефоне | Подсказка управления перекрывала плеер в альбомном режиме | Подсказка скрывается на низком экране; подписи органов управления остаются |
| Отсутствие WebGL | На неподдерживаемом устройстве двор не давал понятного выхода | Сообщение и ссылка на обычный плеер; проверено с принудительно отключённым WebGL |
| Мини-карта | Весь участок показывался сразу | Круглая карта, игрок по центру, радиус 45 м, прокрутка вслед за игроком, стрелка направления. География рисуется в кеш один раз, на обновлениях берётся только нужный фрагмент |
| Защита файлов backend | Range-запрос `/media/../.git/config` обходил проверку доступа | Защита до чтения, ограничение каталогом `media`, защита HEAD; тесты на временных фикстурах, не на личных файлах |
| Вход и API | Неявная выдача OTP без SMTP, неограниченные попытки, отражение чужого Origin, большие тела и история | Без SMTP вход закрыт, demo только явно; лимиты OTP/чата/тела/истории; same-origin; XFF только от доверенных proxy |
| Статический хостинг без API | Отсутствующий backend маскировался браузерной «авторизацией» | На HTTP(S) нет подмены общего аккаунта localStorage-демо. File-preview остаётся локальным демонстрационным режимом |
| Публикация | Старые версионные файлы удалялись заранее, HTML загружался до ресурсов, ошибки AWS игнорировались | Ресурсы первыми, HTML последними, старые версии сохраняются; любой ненулевой AWS exit code прерывает процесс |

## Выполненные проверки

- `python -m unittest discover -s tests -p 'test_*.py' -q`: **53 теста — OK**. Включает HTTP-проверки с временными базами и четыре sandbox-теста PowerShell-публикации с подставным AWS, без обращений к бакету.
- `node --test tests/*.cjs`: **32 теста — pass, 0 fail**.
- `node --check` для изменённых основных JS-файлов: без синтаксических ошибок.
- `git diff --check`: без ошибок пробелов; Git сообщает только о правилах LF/CRLF.
- Проверка локальных ссылок HTML/импортов двора/плейлиста: **46 уникальных путей**, отсутствующих файлов и несовпадений регистра не найдено.
- `python tests/browser_release.py http://127.0.0.1:8765/`: **Failures: 0** на изолированном локальном сервере с временной БД и без SMTP.
- Главная: 1440×900, 1024×768, 800×600, 640×800, 390×844, 320×568, 844×390. Проверены открытие/сворачивание чата, клавиатура, изменение ширины, история, вход из чата, темы и реальный запуск аудио.
- Двор: 1440×900, 390×844, 844×390. Проверены WebGL-отрисовка, размещение элементов, playback/next/home, форма и следование мини-карты, а также fallback без WebGL.
- Ошибок JavaScript в проверенных обычных сценариях браузер не сообщил.

## Доказательства и ограничения

Браузер: Microsoft Edge через Playwright, headless; узкие экраны с эмуляцией touch там, где указано в скрипте. Это не тест на физических iPhone/Android и не гарантия FPS на слабых GPU. Тяжёлая переработка 3D и изменение художественного оформления не выполнялись.

Скриншоты записаны в `%TEMP%/inteon-release-qa`: `chat-*.png`, `player-*.png`, `yard-*.png`. Финальная круглая карта проверена визуально на `yard-1440.png` и `yard-390.png`.

Доставка SMTP проверена только через mock. Реальная авторизация/доставка письма, TLS, proxy/CDN, общие сессии между устройствами и удалённая публикация требуют отдельной приёмки на сервере. Перед коммитом включите новые исходники и тесты, в том числе `playback-link.js`; автоматически коммит не делался.
