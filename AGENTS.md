# Интеонмтека

Каждую готовую правку сайта проверь и сразу опубликуй на https://inteonmteca.online/. Отправь коммит в `main`, дождись публикации и проверь изменённую функцию на публичном сайте. Отдельное подтверждение для обычной выкладки уже дано. Если пользователь попросил оставить конкретный эксперимент локально, следуй его указанию.

При параллельной работе включай в свой коммит только файлы и фрагменты своей задачи. Если несколько агентов делают одну правку, её публикует ответственный за общий результат. Для отката создай обратный коммит и проверь сайт после его публикации.

Порядок выпуска веб-части, аудиомастеров и общего чата описан в [инструкции по публикации](docs/release-deployment.md).
