# inteonmteca Android shell

Это минимальное Android-приложение на WebView. Оно использует ту же страницу, графику, эффекты и `playlist.json`, что и сайт:

- адрес страницы: `https://inteonmteca.online/`;
- треки и обложки остаются на сервере;
- приложение не нужно пересобирать после изменения плейлиста;
- запуск аудио оставлен только по нажатию пользователя;
- JavaScript и DOM storage включены для графики, меню и счётчика.

## Что сделать на Windows

1. Установить Android Studio и Android SDK Platform 35. Android Studio поставит совместимый JDK.
2. Открыть в Android Studio папку `D:\Dev\inteonmteca\android-app`.
3. Дождаться Gradle Sync.
4. Выбрать эмулятор или подключить телефон с включённой USB-отладкой.
5. Нажать **Run** для проверки.
6. Для APK: **Build → Build APK(s)**. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Командная сборка после установки Gradle/Android SDK:

```powershell
cd D:\Dev\inteonmteca\android-app
gradle assembleDebug
```

## Как обновлять музыку

В основной папке сайта добавляется аудио в `media\\Имя_папки\\Исполнитель - Название.ext`. Обложка кладётся в соответствующую папку `assets\\Имя_папки\\`.

Затем из корня репозитория запускается:

```powershell
cd D:\Dev\inteonmteca
powershell -ExecutionPolicy Bypass -File .\deploy-site.ps1
```

Скрипт сам:

1. прочитает имена аудиофайлов;
2. найдёт обложки;
3. пересоберёт `playlist.json`;
4. загрузит треки, обложки и манифест на сервер.

После этого сайт и Android-приложение увидят новый случайно перемешанный плейлист. Приложение пересобирать не нужно.

## Ограничение первой версии

Это онлайн-оболочка: для загрузки новых треков нужен интернет. Если понадобится полностью нативный офлайн-плеер с Media3, фоновым воспроизведением и кешированием, следующим этапом заменим WebView на нативный Android-плеер, сохранив тот же `playlist.json`.
